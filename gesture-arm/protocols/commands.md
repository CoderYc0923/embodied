# 命令协议 v2（手部跟随）

> 与 [docs/DESIGN.md](../docs/DESIGN.md) 保持同步。修改协议时先改本文件。  
> 相对 v1：由「离散手势命令」改为「连续关节流 + 少量控制命令」。

## 串口参数

- 波特率：`115200`
- 数据位：8
- 无校验
- 停止位：1
- 行结束：`\n`

## 连续控制（主路径）

### `J` — 关节角度帧

格式：

```text
J,<j1>,<j2>,<j3>,<grip>
```

| 字段 | 含义 | 单位 / 范围 |
|------|------|-------------|
| `j1` | 底座 yaw | 度，固件内限幅（如 0–180） |
| `j2` | 肩 / 大臂 | 度 |
| `j3` | 肘 / 小臂 | 度 |
| `grip` | 夹爪 | 度或 0–100（实现时二选一，需在固件写死） |

示例：

```text
J,90,120,60,30
```

发送策略：

- 目标频率：**15–30 Hz**（先 20 Hz）
- PC 侧先做平滑与死区，再发送
- 变化小于死区则**不发送**，减轻串口与舵机负担
- 手丢失超过 N 帧：停止发送新目标，臂保持最后合法姿态（或缓回 `HOME`，可配置）

### （可选）`T` — 归一化目标点

若希望固件做 IK / 映射，可用：

```text
T,<x>,<y>,<z>,<grip>
```

- `x,y,z`：`0.0～1.0` 工作空间归一化坐标  
- 第一期**不优先**：百元 4DOF 臂 IK 不稳定，建议 PC 直接算关节角发 `J`

## 控制命令（辅路径）

| 命令 | 方向 | 含义 |
|------|------|------|
| `PING` | PC → Arm | 连通测试 |
| `PONG` | Arm → PC | 回应 PING |
| `HOME` | PC → Arm | 回到初始姿态 |
| `ENABLE` | PC → Arm | 允许跟随（接收 `J`） |
| `DISABLE` | PC → Arm | 暂停跟随，保持当前角 |
| `STOP` | PC → Arm | 立即停止插值（若有） |
| `OK` | Arm → PC | 命令接受 |
| `ERR:UNKNOWN` | Arm → PC | 未知命令 |
| `ERR:RANGE` | Arm → PC | 角度超限被拒或被夹紧 |

## 手部特征 → 控制量（PC 侧映射，不进串口）

| 手部特征 | 控制量 | 说明 |
|----------|--------|------|
| 手腕 / 食指指尖的图像 x | → `j1` | 左右跟随 |
| 手腕 / 食指指尖的图像 y | → `j2`（及可选 `j3`） | 上下 / 伸展 |
| 手部尺度或双点深度代理 | → `j3` 或伸展量 | 前后（近似） |
| 拇指–食指距离 | → `grip` | 捏合越近夹爪越闭 |

## 开发开关

- `dry-run`：只打印 `J,...`，不写串口
- `mirror=true`：画面镜像，左右与直觉一致
