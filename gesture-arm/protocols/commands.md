# 命令协议 v2（手部跟随 / 统一后端）

> 与 [docs/DESIGN.md](../docs/DESIGN.md) 保持同步。  
> 同一套命令供 **仿真后端** 与 **真机串口后端** 使用；上层不关心执行器是谁。

## 统一控制语义

上层（感知 + 映射 + 滤波）只产出：

- 连续关节目标：`JointFrame(j1, j2, j3, grip)`
- 少量控制事件：`HOME` / `ENABLE` / `DISABLE` / `STOP`

后端实现：

| 后端 | 传输方式 | 阶段 |
|------|----------|------|
| `SimArmBackend` | 进程内调用 / 本地 API | 主开发期 |
| `SerialArmBackend` | 串口文本协议 | 真机后置 |
| `ConsoleBackend` | 打印日志 | 调试 |

## 串口参数（仅真机）

- 波特率：`115200`
- 数据位：8
- 无校验
- 停止位：1
- 行结束：`\n`

## 连续控制（主路径）

### `J` — 关节角度帧

格式：

```text
J,<j1>,<j2>,<j3>,<grip>
```

| 字段 | 含义 | 单位 / 范围 |
|------|------|-------------|
| `j1` | 底座 yaw | 度，后端内限幅 |
| `j2` | 肩 / 大臂 | 度 |
| `j3` | 肘 / 小臂 | 度 |
| `grip` | 夹爪 | 度或 0–100（实现时写死一种） |

示例：

```text
J,90,120,60,30
```

发送 / 下发策略：

- 目标频率：**15–30 Hz**（先 20 Hz）
- 先平滑与死区，再交给后端
- 变化小于死区可跳过
- 手丢失：停止更新，保持最后合法姿态（或缓回 `HOME`，可配置）

### （可选）`T` — 归一化目标点

```text
T,<x>,<y>,<z>,<grip>
```

- 供进阶 IK 使用；第一期仍以 `J` 为主
- 仿真期可先在 PC 侧做简易 IK，再下发 `J`，保持后端简单

## 控制命令（辅路径）

| 命令 | 含义 |
|------|------|
| `PING` / `PONG` | 连通测试（真机）；仿真可直接返回成功 |
| `HOME` | 回到初始姿态 |
| `ENABLE` | 允许跟随 |
| `DISABLE` | 暂停跟随，保持当前角 |
| `STOP` | 立即停止插值（若有） |
| `OK` | 命令接受 |
| `ERR:UNKNOWN` | 未知命令 |
| `ERR:RANGE` | 角度超限被夹紧或拒绝 |

## 手部特征 → 控制量（PC 侧，不进后端协议）

| 手部特征 | 控制量 | 说明 |
|----------|--------|------|
| 手腕 / 食指指尖的图像 x | → `j1` | 左右跟随 |
| 手腕 / 食指指尖的图像 y | → `j2`（及可选 `j3`） | 上下 / 伸展 |
| 手部尺度或深度代理 | → `j3` 或伸展量 | 前后（近似） |
| 拇指–食指距离 | → `grip` | 捏合越近夹爪越闭 |

## 开发开关

- `backend=sim|serial|console`
- `mirror=true`：画面镜像
- 仿真与真机切换**只改后端配置**，不改感知与映射代码
