# 手部跟随桌面机械臂（Gesture Arm）

低成本入门具身智能练手项目：摄像头跟踪手部 → **连续跟随控制**桌面舵机机械臂（非遥控器、非按键手势档位）。

## 路径策略

**软测（电脑）→ 真臂接入 → 端侧芯片（去电脑）**

完整设计见：[docs/DESIGN.md](./docs/DESIGN.md)
